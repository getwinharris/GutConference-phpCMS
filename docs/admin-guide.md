# Admin Guide

Admin URL: `/admin`

Admin areas:

- Events & Classes: create/publish event-like records, assign slug URLs, choose payment mode, and store payment page links.
- Page Sections: edit outcomes, audience, trust, FAQ, policy, and custom sections.
- Speakers: manage speaker lineup, credentials, and photos.
- Agenda: manage session schedule.
- Venues & Maps: manage online joining notes, addresses, map links, and embeds.
- Registrations: view registration/payment records.
- Notification Templates: configure email and WhatsApp template metadata.
- Notification Queue: view pending/sent/failed messages.
- Media: upload event, speaker, venue, and shared assets.
- Integrations: Razorpay, SMTP, Meta WhatsApp Cloud API, Google OAuth, and Google Calendar settings.
- Settings: featured event, currency, timezone, and admin credentials.
- Environment: edit `.env` and storage permissions.

Event Management groups Events & Classes, Page Sections, Speakers, Agenda, Venues & Maps, and Registrations in the sidebar. Only admins can create conference content.

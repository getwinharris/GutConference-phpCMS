# GutConference Docs

- Keep docs aligned with the current GutConference CMS product, not the source project.
- Default local server port is `6040`.
- Admin workflow documentation should refer to the `gutconference-admin` skill and broad project work should refer to `gutconference-orchestrator`.
- Keep `Design.md` aligned with current project colors, interaction tone, UI constraints, and any user-provided reference style.
- Document automation-first admin behavior when product rules change: derive labels, timers, ticket counts, and notification timing from event/settings data.
- If a product workflow changes, update `AGENTS.md`, `README.md`, `example-Agent.md`, `Design.md` when relevant, and the matching skill files under `.agents/skills/`.
